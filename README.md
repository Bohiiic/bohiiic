# Bohiiic

A minimal Hello World website built with plain HTML and SCSS, bundled with
Vite.

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:5173>.

## Build

```bash
npm run build
```

The output is generated in `dist/` and uses `dist/index.html` as the entry
file.

## Preview production build

```bash
npm start
```
